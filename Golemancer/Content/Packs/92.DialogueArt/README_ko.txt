엔린 대화 이미지팩 v2 — 최신 설정화 반영

설치
게임을 종료한 뒤 압축파일의 Content 폴더를 게임 루트(Start.bat 옆)에 합쳐줘.
Content/Packs/92.DialogueArt/의 pack.xml, sprites.xml 등 같은 이름의 파일은 덮어쓰면 돼.
이미 v1을 설치했다면 같은 팩을 갱신하고, 처음 설치한다면 그대로 새로 추가돼.
기존 enrin_expressions_a.png / enrin_expressions_b.png는 v2에서 참조하지 않아. 남아 있어도 괜찮아.
이전 팩에 있던 훈증기 불꽃·연기 이미지는 그대로 포함했어.
별도 빌드 없이 현재 대화 애니메이션 지원 빌드(1c59fa0 이후)에서 사용할 수 있어.

기준 원화
엔린과 칠키의 골렘 공방 설정집.png — 2026-09-29 23:33 KST 생성본.
긴 잿빛 베이지색 양갈래 땋은 머리, 녹색 눈, 짙은 녹색 의상과 금색 자수,
흰 프릴, 가죽 벨트, 에메랄드 팔찌, 머리 리본에 고정된 칠키와 칠판을 반영했어.

표정과 포즈
neutral: 평온하고 나른한 표정 / 손으로 볼 받치기
tired: 피곤한 표정 / 관자놀이에 손 대기
smile: 만족스러운 미소 / 앞에서 손 모으기
worried: 걱정 / 옷깃 가까이 손 올리기
surprised: 놀람 / 손을 들어 반응하기
curious: 호기심 / 손바닥을 펴서 설명하기
기존 sleepy는 tired, happy는 smile에 연결돼.

시트와 재생
각 PNG는 1536×1024, 왼쪽은 입 닫힘, 오른쪽은 말하는 입 모양이야.
기본 초상 프레임은 왼쪽 768×1024 영역이야.
말할 때에는 sprites.xml의 talk 영역과 overlayX/overlayY를 사용해 입 주변만 겹쳐 그려.
오른쪽 인물 전체를 번갈아 표시하지 않으므로 몸, 머리, 장신구가 떨리지 않아.
입 위치와 표정별 파일 경로는 XML에서 변경할 수 있어.
대사 출력 중 입 움직임, 클릭 시 즉시 전체 출력, 등장 연출은 기존 대화 시스템이 담당해.

제작
내장 image_gen으로 생성했어. 최종 PNG는 생성 원본 그대로 복사했으며 재인코딩하지 않았어.
최종 프롬프트와 생성 방식은 ART_PROMPTS.txt에 기록했어.
투명도, XML의 이미지 경로, 프레임·입 오프셋 범위, 대사 표정 연결 및 ZIP 무결성을 검증했어.
Windows 게임 화면에서의 실제 재생은 이 작업 환경에서 실행하지 못했어.
이미지를 포함한 팩은 이 압축파일로 전달하며 Git에 올리지 않았어.
