# Pre-separation save fixture

`pre-separation-save.json` was generated by the actual pre-separation net10.0 Engine/Contracts binaries shipped with commit 80f792a (frozen source cc1d670, runtime baseline c77bcdc). It starts from the original campaign world and adds a fractional actor position, mana, over-capacity inventory, a recorded movement, unknown JSON properties and an object from a missing pack.

EngineSeparationTests loads this fixture through the new game runtime, checks state preservation, advances the world and saves/loads it again. Do not regenerate the fixture with the new runtime: its purpose is compatibility with the previous assembly boundary. It contains generated test state, not a player's save.
