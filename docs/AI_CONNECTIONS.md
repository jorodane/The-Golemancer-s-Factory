# 내부 AI 에이전트 연결

Confectory는 내부 작업 AI만 연결한다. 첫 화면에서 저장된 에이전트를 선택하거나 **에이전트 연결**로 추가한다. **나중에**를 누르면 AI 없이 프로젝트 목록으로 이동한다. 왼쪽 AI 관리에서 여러 연결과 도우미를 관리한다. 전체 설계는 [내부 AI Studio](INTERNAL_AI_STUDIO.md)를 따른다.

| 제공자 | Windows | Android |
|---|---|---|
| Codex | 이 PC의 CLI·ChatGPT 계정 로그인 | 미지원 |
| Claude | Anthropic API 키 | Anthropic API 키 |
| OpenAI | OpenAI API 키 | OpenAI API 키 |
| 외부 제공자 | `IEditorAssistant` DLL | 미지원 |

API 에이전트를 추가할 때 키와 모델을 입력하고 API 전송·과금 동의를 확인한다. 모델 목록 조회와 인증 확인 후 연결을 저장한다. Windows에서 기존 에이전트의 설정을 고칠 때는 키를 비워 두면 그 에이전트의 저장된 키를 사용한다. 새로운 에이전트에는 새 키를 입력한다. 같은 제공자의 여러 연결도 별도의 인증 슬롯을 쓴다. 키는 Windows DPAPI 또는 Android Keystore로 암호화하며 프로젝트·팩 ZIP·일반 설정 JSON에 포함하지 않는다.

Codex는 기존 설치·로그인을 재사용한다. 설치가 필요하면 위치·설치를 안내하고, 계정 승인은 Codex 로그인 화면에서 진행한다. 새 프로젝트를 열었다는 이유로 Codex 설치나 저장된 요청을 자동 실행하지 않는다. 같은 PC의 Codex 프로필은 같은 로그인 원본을 사용하되 작업자별 대화는 분리한다.

작업자는 선택한 에이전트에서 독립 제공자 세션을 만든다. 제공자 API 대화와 로컬 작업 로그, Codex 저장 대화를 구분한다. 재연결 시 해당 작업자의 최근 비공개 경험만 제한된 분량으로 전달한다. 프로젝트 공개 호출·제안 검토에는 이 개인 경험을 제공하지 않는다.

웹 AI 패널, 웹 계정↔프로젝트 링크, ChatGPT 플러그인, WebView2와 터널은 제거했다. 과거 설정은 연결 권한으로 해석하지 않는다. 이미지 생성 연결은 사용자가 별도로 설정하는 내부 제작 도구로 유지한다.
