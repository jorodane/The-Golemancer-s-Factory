데굴돌 전용 아트팩 v1

적용 방법
1. 데굴돌 수정 빌드(3f1a5c8 또는 그 이후)를 준비하고 게임을 종료해.
2. 압축파일의 Content 폴더를 Start.bat가 있는 게임 폴더에 합쳐줘.
3. Content/Packs/91.DeguldolArt/pack.xml이 있는지 확인한 뒤 Start.bat를 실행해.
   별도 빌드 없이 팩 로더가 전용 이미지 연결을 적용해.

포함 파일
- Images/rolling_stone.png: 1024×1536 RGBA, 4열×6행, 256×256 셀 24개.
- Images/item_stone.png: 투명 RGBA 돌멩이 아이콘.
- sprites.xml: 데굴돌 6개 애니메이션과 돌멩이 아이콘의 프레임·피벗·표시 오프셋.
- pack.xml: 독립 아트팩 등록. feast_trail 이후에 로드해 기존 임시 연결을 대체해.

시트의 행 순서
대기 / 구르며 이동 / 긴장 / 돌진 준비 / 피격 / 파괴
각 행은 왼쪽에서 오른쪽으로 재생해. 대기는 눈을 깜빡이고, 이동은 실제 네 방향 회전 프레임을 사용해.
돌진 준비는 4프레임×0.2초로 현재 0.8초 예고 시간과 맞췄어.
각 Animation의 offsetX/offsetY는 타일 단위 표시 위치이며, 실제 이동·충돌 좌표와 별개야.
Frame의 좌표·크기·피벗은 원본 PNG를 수정하지 않고 표시 범위와 기준점을 지정해.

이 팩은 두 스프라이트 연결만 제공해. 실행 파일이나 게임 규칙 변경은 포함하지 않아.
되돌리려면 게임 종료 후 91.DeguldolArt 폴더를 제거하면 돼.
이미지 생성 방식과 최종 프롬프트는 ART_PROMPTS.txt에 있어.

검증
- 두 PNG의 실제 투명 알파와 24개 프레임 경계를 확인했어.
- 기존 게임의 팩 로더로 로드 순서, 이미지 경로, 6개 애니메이션 및 아이콘 연결을 확인했어.
- 전용 이미지가 데굴돌 3개체에 연결되고 기존 오브젝트·아이템 정의는 유지돼.
