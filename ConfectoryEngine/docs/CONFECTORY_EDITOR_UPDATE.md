# Confectory 에디터 업데이트 — 2026-10-02

표시 이름을 **Confectory**로 확정했다. 호환용 어셈블리·설정 경로는 유지한다. 마지막 메인/팩 창 위치·크기·최대화 상태와 설정·검토 창 위치를 기기별로 저장한다. 모니터가 사라졌다면 현재 작업 영역 안으로 복원한다.

| 요청 | 반영된 동작 |
|---|---|
| 에디터팩 접근 | 일반 find/inspect/read/patch가 에디터팩 키를 처리한다. DLL 미장착 상태에서도 소스·계약을 조회한다. |
| 새 객체·파일·팩 | 생성 파일과 XML/프로젝트 등록을 하나의 검토 항목으로 모은다. 새 에디터팩의 실제 DLL 뼈대도 생성한다. |
| 생성 검토 | 미적용 파일을 읽고 수정할 수 있다. 전체 경로·버전을 검증하고 중간 실패 복구, 취소, 파일별 결과를 제공한다. |
| 에디터 확장 API | 객체·선언 리소스 카탈로그, 검토 문서 수정, 선택 창, 소유 창의 동적 뷰, 실제 빌드/재로드 결과를 제공한다. |
| 아이콘·수량 UI | Windows wrap/slot, 글리프/bitmap, 수량, hover 툴팁, Text 선택 payload와 `+` 버튼을 구성할 수 있다. |
| 대화 저장 오류 | 임시 이름과 저장 JSONL 이름을 줄였다. 자동 복구본 오류는 경고이며 Codex 원본과 완료된 응답을 유지한다. |
| 대화 복사 | 메시지 드래그/Ctrl+C, 개별 복사와 현재 전체 대화 복사를 제공한다. |
| Yogi 첨부 | 보이는 composer를 검증하고 단계별 오류를 기록한다. 입력창 직접 지정과 수동 파일 첨부 경로를 제공한다. |
| 공유 대화 본문 | 사용자가 선택한 고정 본문과 해시를 전달한다. 메타데이터 URL 등록과 구별한다. |
| 이미지 생성 | 별도 API 연결·유료 사용 선택, 실제 PNG 결과 미리보기/저장, 이미지와 Asset 선언의 검토 등록을 제공한다. |

현재 골레맨서의 `RecipeDef`는 `Output`/`Amount` 하나와 여러 `Inputs`를 가진다. 복수 출력은 게임 계약·실행기 변경이 추가로 필요하며 이번에 지원되는 기능으로 표시하지 않는다. 아이템 의미·레시피 해석은 게임팩이 구현하고 공통 에디터는 UI/API를 제공한다.

Windows에서는 저장소를 업데이트하고 `StartEditor.exe`를 다시 실행한다. Yogi 입력창을 찾지 못하면 첨부 안내의 **입력창 직접 지정**을 사용한다. 이미지는 **에디터 AI → 이미지 생성 연결…**에서 먼저 설정한다. 생성된 PNG나 APK는 Git 배포에 추가하지 않았다.

검증 명령은 `tools/verify-authoring.py`, `tools/verify-yogi.js`, 기존 editor-packs/resident/conversations 검사와 `BuildEditor.bat`이다. 검증은 임시 프로젝트와 명시적 HTTP/DOM fixture를 사용하며 실제 별도 팩 DLL·worker 통신도 실행한다. Windows GUI, 실제 웹 로그인·첨부, DPAPI 기기 실행과 유료 이미지 추론은 이번 Linux 검증에 포함하지 않는다. 새 Windows wrap/slot은 Android에 제공하지 않는다.
