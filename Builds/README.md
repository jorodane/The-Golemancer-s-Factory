# Windows 빌드

[The-Golemancers-Factory-Windows-net48.zip 다운로드](The-Golemancers-Factory-Windows-net48.zip?raw=true)

WPF / .NET Framework 4.8 실행 파일과 엔진·객체팩 DLL, XML 설정이 포함된 최신 검증 빌드야. SDK 없이 실행할 수 있어.

1. ZIP을 쓰기 가능한 폴더에 풀어.
2. 별도로 받은 `The-Golemancers-Factory-Image-Packs-v2.zip`을 같은 폴더에 풀어 `Content` 폴더를 합쳐.
3. `Golemancer.exe`를 실행해. .NET Framework 4.8 런타임이 필요해.

이미 설치했다면 게임을 종료하고 이 ZIP을 기존 설치 폴더에 덮어쓰면 돼. 이미지팩 v2와 `Saves` 폴더는 그대로 사용할 수 있어.
