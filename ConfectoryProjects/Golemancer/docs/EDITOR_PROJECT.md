# 엔진에 로드되는 골레맨서 프로젝트

`Golemancer.packproject`는 이 폴더의 팩·계약·소스 프로젝트와 Windows/Linux 빌드·실행·검증을 선언한다. `editor-schema.xml`은 게임의 Action, Object, Item, Recipe 등의 이름과 연결 의미를 에디터에 제공한다. 이 두 파일은 공통 엔진이 게임의 규칙을 알지 않아도 탐색하고 작업할 수 있게 한다.

전체 저장소에서 `StartEditor.bat`을 실행하거나 에디터에서 이 `.packproject` 파일을 선택한다. 엔진 에디터를 배포받았다면 이 골레맨서 폴더만 복사해서 프로젝트로 열 수도 있다. 게임의 선택한 엔진 SDK, 게임 직접 실행, 기존 DLL 로딩·세이브 경로는 이 프로젝트 선언으로 바뀌지 않는다.

첫 작업으로 `golemancer.controls`의 가격 버튼 XML을 수정하거나 `commerce`의 C# 구현을 열어 개별 빌드를 할 수 있다. 엔진 기본 버튼 구현은 외부에서 제공받는 팩이므로 이 프로젝트에서는 읽기 전용이고, 게임 테마 팩이 상속해서 재정의한다.

프로젝트의 **검증**은 게임의 전체 캠페인 검사를 실행한다. **실행**은 선택한 플랫폼 게임을 별도 프로세스로 시작한다. Linux smoke는 SDL offscreen에서 실제 DLL 로딩과 프레임을 확인한다. WPF 에디터 GUI 조작 검증과 Android/iOS 네이티브 빌드는 별도다.
