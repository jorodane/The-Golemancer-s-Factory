# 독립 프로젝트

Golemancer는 게임 계약, 시뮬레이션, 독립 팩, 콘텐츠, 플랫폼 표시 코드와 프로젝트 설정을 가진 Confectory 프로젝트다. 공통 빌드·시작·검증 도구와 엔진 SDK 구현은 프로젝트에 들어 있지 않다.

선택한 엔진에 프로젝트 경로를 전달하면 엔진이 SDK를 생성하고 그 SDK로 게임을 빌드한다. 프로젝트를 다른 드라이브나 공백을 포함한 폴더로 이동해도 같은 `.packproject`를 사용한다. 엔진 출력물을 먼저 복사하거나 커밋할 필요는 없다.

자세한 명령은 [프로젝트 README](../README.md)와 [엔진의 구조 명세](../../../ConfectoryEngine/docs/PROJECT_LAYOUT.md)를 참고한다.
