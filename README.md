# The Golemancer’s Factory

만사가 귀찮은 골레맨서 **엔린**의 작은 공방. 골렘을 직접 조종하고, 일하는 방법을 기록하고, 생산과 운반을 맡기는 2D 타일 게임이야.

**첫 챕터 ‘만찬의 오솔길’부터 샘물의 왕 처치, 자동화, 미니 골렘 물류, 다음 챕터의 동굴 입구 개방까지 플레이할 수 있어.** 동굴의 후속 챕터 내용은 이번 범위에 포함하지 않아.

## 실행

Windows용 **WPF / .NET Framework 4.8** 앱과 Android용 **네이티브 .NET 10** 앱이야.

Android에서는 별도 다운로드로 제공하는 `Golemancer.apk`를 설치해. APK는 Git 저장소에 올리지 않아. Android 8.0 이상, ARM64 휴대폰과 x86_64 에뮬레이터용 개발 빌드야. 터치·게임패드 조작과 빌드 방법은 [Android 플랫폼 안내](docs/ANDROID.md)에 있어.

저장소를 받거나 pull한 뒤 **루트의 `Start.bat`을 실행**하면 돼. 압축을 풀어둔 [Windows 실행 파일](Builds/README.md)과 모듈 DLL이 함께 들어 있고 .NET Framework 4.8 런타임만 필요해. SDK나 빌드 ZIP 압축 해제는 필요 없어.

실행 파일은 저장소 루트의 `Content`를 읽어. 기존 이미지를 `Content/Packs/<팩>/Images`에 한 번 놓아두면 업데이트할 때도 그대로 사용해. 별도의 실행 폴더로 이미지를 옮기거나 `Content`를 매번 합칠 필요가 없어. 이미지에는 `.gitignore` 규칙을 적용하지 않아서 사용자 Git에서 직접 추가·푸시할 수 있어.

소스를 바꾼 뒤 다시 빌드하려면 .NET 10 SDK를 설치하고 `Build.bat`을 실행해. 실행 파일과 DLL이 같은 위치에 갱신돼. SDK는 빌드 도구이고, 실행 파일의 대상은 **net48**이야. 첫 소스 빌드에는 NuGet 패키지 복원을 위한 인터넷 연결이 필요하고 플레이는 오프라인으로 가능해.

게임 규칙과 저장은 .NET 모듈이 담당해. WPF 창에서 타일과 프레임 이미지를 표시하고 직접 명령을 전달해. 콘텐츠 DLL은 `pack.xml`을 통해 실제 `Assembly.LoadFrom`으로 로드하고, Host는 콘텐츠 모듈 프로젝트를 참조하지 않아.

현재 검증 환경에서 Windows 대상 빌드는 통과했지만, 실제 Windows 창 실행은 아직 확인하지 못했어. 공유 엔진과 앱 세션의 캠페인·회귀 검증은 Linux의 net10.0 대상으로 실행했어. 자세한 범위는 [검증 기록](docs/VERIFICATION.md)에 있어.

| 일상 모드 좌클릭 | 빈 땅: 이동 지시 · 지정된 개체만 빠른 사용 · 나머지는 버블 메뉴 |
| 우클릭 | 클릭 주변의 원형 아이콘 버블 · 호버로 설명 |
| Tab | 현재 골렘의 일상 / 전투 모드 전환 |
| 전투 모드 좌클릭 | 적 공격 |
| E / E 길게 누르기 | 가까운 바닥 물건 한 묶음 / 주변 2칸 범위 물건 줍기 |

| Shift + 행동 선택/확인 | 현재 행동 뒤에 순서대로 예약 |
| R / T | 녹화 시작·종료 / 반복 시작·정지 |
| B / I | 건설 / 장비와 강화 |
| Space / 1 / 2 | 전투 모드로 전환하며 구르기 / 생명력 젤리 / 마나 젤리 |
| X | 현재 작업과 반복 중단 |
| 휠 / 휠 버튼 드래그 / F | 확대·축소 / 일상 카메라 이동 / 선택 골렘 위치 보기 |
| Ctrl / Alt + 수량 액션 | 1개 / 가능한 전체 즉시 실행 |
| 가방 아이템 드래그 | 바닥에 내려놓기 / 골렘·시설에 전달 |
| Esc / 가운데 뒤로가기 버블 | 한 단계 위로 · 최상위는 Esc로 닫기 |

이동·구르기·자동 이동은 연속 좌표로 처리하고 충돌·작업 범위만 타일로 판정해. 녹화에는 지나간 타일 경로를 저장하며 재생도 그 방향으로 움직여. 타일 중심으로 위치를 맞추지 않아. 키 설정은 `Content/Packs/00.Foundation/inputs.xml`에서 바꿀 수 있어.

왼쪽 공방 일지에 현재 목표가 표시돼. 첫 골렘으로 동쪽 널린초를 수확하고 **진열대 좌클릭 → 물건 넣기**로 옮기면 손님이 구매해. 목재는 수확 골렘이, 건설과 제작은 제작 골렘이 담당해.

재료 전달은 **수확 골렘 조종 → 제작 골렘 클릭 → 건네기 → 분류·목재 선택 → 1개 / N개 / 목표 재고 / 가능한 전부** 순서야. 골렘이 멀면 다가가서 전달하고 조종 대상은 유지해. 받는 쪽의 적재 한도와 정해진 수량 / 목표 수량 / 가능한 전부 설정도 적용돼.

건네기와 가져오기, 제작·구매·충전·건설·조립·장비·주문·행동 기록은 같은 재귀 버블 메뉴를 써. 한 페이지에 원형 아이콘 8개가 보이고, 페이지 이동은 아래에 따로 있어. 버튼은 중심에서 95px 거리의 고정된 8방향을 순서대로 채워. 아이콘은 12시부터 시계방향으로 빠르게 퍼져 나오며 한 번 커졌다가 돌아와. 이름은 검은 테두리 글씨로 항상 아래에 표시돼. 대부분의 버튼은 호버 시 크기만 커지고, 제작처럼 상세 정보가 있는 행동만 설명을 보여줘. 한 품목만 있는 분류는 바깥으로 압축되고, 하위 메뉴의 가운데 버튼으로 상위 메뉴에 돌아가. 최상위에는 닫기 버블을 표시하지 않아. 하위 메뉴는 선택한 마우스 위치에서 열리고, 뒤로가면 이전 메뉴의 위치와 페이지를 복원해. 버블은 일지·하단 UI 위를 포함한 게임 창 전체에 펼쳐져. 실제 버튼·제목·수량창이 창 밖으로 나가는 만큼만 중심을 보정하고, 그때만 마우스도 중심으로 옮겨줘. 열린 메뉴 뒤의 UI에는 클릭·휠 입력이 전달되지 않아. 빈 곳을 누르면 메뉴만 닫혀. 페이지 이동이나 재고 갱신 중에는 마우스를 옮기지 않아. 별도 행동 목록 없이 고유 행동을 바로 표시하고, 모드의 XML 분류·조건도 유지해. 많은 항목은 페이지로 나눠. 아이템의 ★ 버튼으로 즐겨찾기를, 대상의 분류 지정 버블로 우선 카테고리를 저장할 수 있어.

제작 아이콘에 마우스를 올리면 해당 버튼을 제외한 화면이 살짝 어두워지고, 버튼 위에 결과물 이미지·설명과 재료별 보유/필요 수량이 보여. 부족한 재료는 붉게 표시해. 재료나 완성품 공간이 부족한 레시피도 목록에 남지만 버튼은 회색으로 비활성화돼. 비활성 버튼도 호버 설명을 볼 수 있고 재료가 준비되면 다시 활성화돼. 화면 위쪽 끝에서는 설명을 옆으로 옮겨 버튼을 가리지 않아. 건설·조립은 필요한 재료, 구매는 금화와 구매 가능 수량, 운반은 출발·도착 재고를 보여줘.

행상인의 구매 선택지는 금화·가방 공간·해금 상태에 맞춰 제한돼. 최대 1개만 살 수 있으면 1개 구매만, 2개 이상이면 N개 구매도 표시해. 책은 1권으로 레시피를 영구 해금하며 이미 읽은 책은 비활성화돼. Ctrl/Alt 빠른 구매에도 같은 제한이 적용돼.

N개를 선택하면 숫자 필드, 정수 슬라이더, `−10 / −5 / −1 / +10 / +5 / +1 / 1개 / 중간 / Max`와 마우스로 누르는 확인 버튼이 나타나. Ctrl과 함께 수량 액션을 누르면 1개, Alt와 누르면 가능한 전체를 바로 실행해. 모든 입력은 같은 최대 수량에 맞춰 연동되고 실행 직전에 다시 확인해.

Shift로 행동을 선택하면 현재 행동 뒤에 예약해. Shift로 연 버블은 하위 메뉴에서도 예약 상태를 유지해. 넣기·꺼내기는 현재 작업과 앞선 예약을 마친 **예상 재고**에 있는 종류와 수량만 보여줘. 수확 후 전달, 가져온 재료로 제작 후 전달도 반영해. 모든 골렘의 현재 경로와 예약 목적지는 번호가 있는 선으로 이어져. Shift 없는 새 작업·이동 지시는 현재 행동과 남은 예약을 교체하고 점유를 해제해. 다른 골렘으로 조종을 전환하면 이전 골렘은 마력이 있는 동안 예약을 이어가고, 마력이 없으면 현재 작업과 예약을 보존한 채 대기해.

월드가 창 전체를 채워. 일지는 투명한 작은 영역에 목표를 표시하고 접을 수 있어. 골렘 관리는 평소 접혀 있으며 종류별 원형 아이콘, 내구도·마력 테두리 게이지, 조립 + 버튼을 제공해. 아이콘 호버는 실제 골렘을 강조해. 좌하단에는 가방 아이콘·개수·최대 슬롯과 선택 골렘의 행동 그리드가 있고, 행동 묶음은 컨텍스트 메뉴와 같은 압축 규칙으로 탐색해. 아이템을 드래그하면 포인터에 아이콘과 전달 대상이 표시돼. 시계의 시계방향 게이지로 남은 하루를 보여주고 날짜가 바뀌면 화면에 알려줘. 일상은 자유 카메라, 전투는 선택 골렘 추적이야.

R로 녹화를 마칠 때에는 진행 중인 행동과 **아직 실행하지 않은 예약**까지 한 번씩 저장해. 재생 시에는 일반 행동 순서로 실행해. 행동이 실제 시작되면 이동하는 동안부터 필요한 수량을 **점유**하고, 다른 골렘·자동 생산·판매는 남은 수량만 쓸 수 있어. 완료·실패·취소·파괴 시 점유를 해제해. 다른 골렘에게서 가져오는 물건은 예외로 도착 시 수량을 확인해.

수확물은 먼저 바닥에 나타난 뒤 수확한 골렘이 자동으로 주워. 보관함에 안 들어가는 수량은 바닥에 남아. 인벤토리 아이템을 눌러 내려놓은 물건과 철거·파괴 부산물은 E로 직접 주워야 해. E를 0.35초 이상 누르면 주변 범위를 한 번에 수집해.

골렘 행동 목록 또는 땅 우클릭의 **이 주변 아이템 줍기**는 지정 지점 주변 6칸의 바닥 물건을 찾아 다가가서 수집해. 직접 버린 물건과 사망한 골렘의 일반 소재도 이 명령으로 회수할 수 있어. 물건이 없거나 가방이 차면 기준 지점으로 돌아와 기다리고, 새 물건이나 빈 공간이 생기면 다시 움직여. 갈 수 없는 물건은 건너뛰며 초과분은 바닥에 남겨. 기준 지점과 명령은 녹화·저장에 포함되고 새 지시나 X로 해제해.

화면 안의 골렘을 직접 선택하면 카메라 위치를 유지해. 관리창·단축키로 선택하거나 화면 밖의 대상을 선택하면 그 골렘으로 화면을 옮겨. 선택만으로 반복·진행 중인 작업·예약을 취소하지 않아. 메모리 창의 일시정지/재개는 작업 진행도와 대기 시간도 보존해.

바쁜 골렘의 **물건 가져오기**는 상대 작업을 멈추거나 접근 중에 재고를 점유하지 않아. 도착했을 때 요청한 수량이 없어졌으면 실패해. **동행 요청**은 상대의 기존 작업을 보존해 따라오게 하고, 방전된 골렘은 구조하는 쪽이 느려지며 끌고 가. 충돌과 연결 거리를 지켜 벽을 통과하지 않아. 마력이 든 수정탑에 붙인 뒤 상대 골렘의 **대신 충전**을 사용하고 **동행 마치기**를 누르면 기존 작업을 이어가.

**메모리 창**은 우하단 버블 버튼 위에 열려. 목록에서 장착할 수 있고 이름을 클릭하면 타임라인이 나와. 키프레임의 크기·색으로 행동을 구분하고, 마우스를 올리면 대상·수량·시간·최근 실패를 확인해. 클릭은 시작점만 선택하며 **여기부터 반복**으로 실제 재생해. 실행 위치는 별도 표시해.

선택한 프레임을 삭제하거나 좌우로 옮기고 Ctrl+Z/Ctrl+Y로 되돌릴 수 있어. **여기부터 재녹화**는 앞부분을 남기고 선택 지점 이후를 직접 플레이로 교체해. R로 마친 뒤 초안을 검토하고 저장해. 재료 공급을 지워 뒤의 전달/제작이 불가능해지는 등의 오류는 빨간 프레임으로 표시하고 저장을 막아. 일시적인 자원 고갈은 오류와 구분해 설명해. 이전 메모리는 현재 가방을 시작 재고로 검사해. 닫기·Esc·목록 복귀는 미저장 변경을 버리며, 이미 실행 중인 골렘은 편집 전 저장본으로 계속 실행해. 새 저장본은 다음 재생에 적용돼.

기본 반복 실패 처리는 뒤의 키프레임을 먼저 확인해. 한 순환에서 모든 행동이 실패하면 2초 기다렸다가 전체를 다시 확인해. 특정 프레임에 지정한 중단·건너뛰기·재시도 정책은 유지해. 달달과나무의 기본 클릭은 **열매 수확**, 목재 수집은 **베어넘기기**야. 열매가 없을 때에는 여름·가을의 결실을 기다리는 상태를 설명해.

돌멩이는 주 동선 남쪽 돌밭의 **데굴돌**에게서 얻어. 사계절 낮·밤 모두 영역에 접근하면 예고된 방향으로 돌진하고, 벗어난 상대를 잠시 추격하다 돌밭으로 돌아가. 타격에 약하며 처치한 골렘이 바닥에 떨어진 돌멩이를 자동 습득해. 가방 초과분은 바닥에 남아 E로 주울 수 있어. 이전 저장의 잘못 추가된 돌멩이 정령은 같은 개체 ID의 데굴돌로 정정하고 체력·소지품·모드 데이터를 유지해.

데굴돌의 내부 ID `rolling_stone`과 체력 35·공격력 6·돌멩이 6개 등의 수치는 검증용 임시 값이야. 원래 기획에서 수치는 미정이었어. 전용 외형 시트는 현재 팩에 없어 기존 돌 주먹 시트를 작게 연결했고, 돌밭도 기존 외부 지면 이미지를 재사용해. 전용 이미지가 완성된 상태는 아니야.

## 첫 챕터의 흐름

| 단계 | 플레이 내용 |
|---|---|
| 1–3 | 수확과 일반 판매 → 제작 핵 구매·조립 → 훈증기 건설과 목제 무기 제작 |
| 4–6 | 샘물주머니 사냥 → 젤리와 회복약 생산 → 상점 확장·평판 → 복합 주문 납품 |
| 7–9 | 돌 주먹·물 몸통 보스전 → 채광 핵과 수정맥 → 마나 활용서와 수정탑 |
| 10–12 | 충전·채집·운반 녹화 반복 → 한 칸 미니 골렘 운반 → 다음 챕터 입구 개방 |

- 현재 직접 조종하는 골렘만 마력이 없어도 효율 50%로 일해. 조종하지 않는 골렘과 녹화 재생은 마력 소진 시 멈춰. 이동 경로·작업 진행도·재료 점유·예약을 보존하고 충전하면 이어가며, 반복 중이 아닌 골렘은 다시 조종해도 움직일 수 있어. 공격과 영역 수집에도 마력이 소모돼. 충전을 녹화에 포함하면 안정적으로 순환할 수 있어.
- 훈증기는 **연료·약초·액체 전용 투입칸**을 써. 각 칸에는 한 종류씩 최대 50개를 넣고, 호환되는 재료와 목재/남은 열이 준비되면 자동으로 생산해. 마우스를 올리면 연료·약초·액체·출력 네 칸이 이미지와 개수 버블로 보여. 시설을 좌클릭하면 주변을 어둡게 표시하고 시설과 투입칸에 집중해. 각 칸의 좌클릭은 호환되는 품목 넣기, 우클릭은 그 칸에서 꺼내기야. 품목이 하나면 수량 슬라이더로 바로 넘어가. 입력칸이 있는 다른 시설도 같은 방식을 써. 완성품은 별도로 쌓이며 출력 버블에서 꺼내. 기본 샘물젤리는 입문서 없이 만들고 회복 젤리 레시피는 책으로 해금해. 목공 작업대는 **제작 골렘이 가진 재료**로 수량·목표 재고를 지정해 제작해.
- 작업대·훈증기·창고·수정탑은 야외의 빈 땅에도 건설할 수 있어. 판매 진열대만 상점 안으로 제한하고 상점의 판매 시설 한도를 적용해. 새 게임의 목공 작업대는 상점 동쪽 야외에 있어.
- 보관·운반은 정해진 수량 / 목표 수량까지 / 가능한 전부를 지원해. 미니 골렘은 한 칸이지만 직접 조종과 녹화가 가능해.
- 일반 핵은 구매·보상으로 얻고, 미니 핵만 제작해. 파괴된 골렘의 핵은 즉시 공방으로 돌아오고 물건은 현장에 떨어져. 엔린이 다시 조립할 수 있어.
- 샘물의 왕의 주먹에는 망치, 물 몸통에는 검을 써. 주먹은 재생되며 공격 범위가 바닥에 예고돼. 후퇴하면 전투가 초기화되고, 처치한 보스는 돌아오지 않아.
- 봄낮·봄밤·여름낮·여름밤·가을낮·가을밤·겨울낮·겨울밤의 8단계 달력을 사용해. 각 단계는 15일, 하루는 게임 시간 180초야. 밤의 적 행동과 자원 재생, 겨울낮 15일의 축제 대사가 연결돼 있어.

## 이미지와 애니메이션 객체팩

실제 이미지 파일을 독립 객체팩으로 나눴어.

| 팩 | 내용 |
|---|---|
| `04.TerrainRules` | 외부 이미지에 적용할 풀·흙·매끄러운 경계·실 마스크 DLL |
| `05.FeastTrailTiles` | 지형 SVG와 통행 여부, 영역 합성·번짐·수신 경계 설정 |
| `06.FeastTrailArt` | 시설·자원·아이콘·엔린 초상화 등의 SVG |
| `07.FeastTrailAnimations` | 투명 PNG 시트 12장, 기본 캐릭터 애니메이션 |
| `91.DeguldolArt` | 데굴돌 전용 PNG 24프레임과 돌 아이콘. 기존 임시 연결을 덮어씀 |

정지 캐릭터 전체를 위아래로 흔드는 효과는 없어. 대기·이동·작업·공격·피격·쓰러짐 상태에 맞는 실제 프레임을 재생해. 애니메이션마다 시트 파일, 영역, 속도, 반복 여부, 크기와 `offsetX/offsetY`를 지정할 수 있어. 오프셋의 단위는 타일이고 충돌·저장 좌표와는 독립적이야.

엔린의 **에메랄드 팔찌, 머리 위 계산 미니골렘, 감정 칠판**을 시트와 초상화에 포함했어. 이미지가 없으면 누락된 파일 경로를 안내해. 이미 제공한 이미지팩 v2를 그대로 사용할 수 있어. 이미지는 저장소 루트의 `Content`에서 유지하고 실행 파일 갱신 시 복사하거나 삭제하지 않아.

새 그림이나 타일셋은 팩의 XML과 이미지로 교체할 수 있어. [이미지팩·애니메이션 명세](docs/ART_PACKS.md)에 시트 단위 등록, 오프셋, 패치 팩 예제가 있어. `tools/export-art.mjs`는 기존 정적 SVG를 내보내는 선택적 제작 도구이며 게임 실행 중에는 사용하지 않아.

바닥은 8×8칸 영역 이미지로 합성해 캐시하고, 수정된 주변만 갱신해. 처음 보는 영역의 정밀 합성은 화면을 막지 않도록 별도 작업자에서 처리해. 풀은 무리와 빈 틈, 흙은 부드러운 경계와 흩어진 알갱이를 만들고 나무바닥은 좁은 끝부분만 다른 지형을 받아들여. 카펫처럼 위에 덮는 층, 실 가닥 경계와 별도 마감 이미지도 팩으로 지정할 수 있어. [지형 규칙·레이어 명세](docs/TERRAIN_PACKS.md)에 XML과 DLL 확장 방법을 정리했어.

## 저장

`Saves/manual.json`과 `Saves/autosave.json`에 저장해. 자동 저장은 게임 시간 30초 간격이고, 이전 파일은 `.bak`으로 남겨. 타일 상태, 건물 좌표, 골렘의 칸 내부 위치와 재고, 바닥 물건, 진행 중인 생산, 행동 예약 순서와 재고 점유, 행동 녹화와 반복 위치, 퀘스트가 함께 보존돼. 이전 정수 좌표 세이브도 불러올 수 있어. 설치하지 않은 팩의 객체 데이터와 기존 초과 재고도 지우지 않아.

## 검증

Windows의 `Verify.bat`은 저장소에 포함된 net48 검증 프로그램으로 캠페인·회귀 검증과 WPF `--smoke` 검증을 실행해. SDK 없이 현재 빌드를 확인할 수 있어. 창 검증은 로컬 `Content`의 기존 이미지를 사용하고, 별도 테스트 세이브와 `TestResults/windows` 결과·화면을 남겨. 소스를 수정했다면 `Build.bat`으로 빌드를 갱신한 뒤 실행해.

Linux/macOS의 `bash verify.sh`는 WPF를 제외한 같은 엔진·모듈과 앱 세션을 net10.0으로 빌드해 검증해. 자유 이동·녹화 경로, 수확→골렘 전달→야외 건설, E 줍기, 12개 퀘스트, 수량·용량, 무마력 정지·재개, 생산 중 저장, 핵 회수, 보스 초기화, 미설치 팩 데이터 보존, 대사·일시정지, 이미지팩 메타데이터를 확인해.

아트 제작 환경에서 `python tools/verify-art.py`를 실행하면 실제 파일·투명도·프레임 영역을 검사하고 시트 미리보기를 만들어. Pillow와 numpy가 필요해. 별도 전달용 ZIP이 필요한 경우에만 `python tools/package.py <출력폴더>`를 사용해. 저장소에서 실행·검증할 때는 이 단계를 거치지 않아.

이번 버전은 로컬 싱글플레이야. 멀티플레이, 모바일 조작, 다음 챕터 내부 지역은 구현 범위 밖이야.
